# 🌤️ Momentum — персонализированный дашборд

Аналог браузерного расширения Momentum: часы, приветствие, погода, цитаты, музыкальный плеер и смена фоновых изображений.

## 🛠️ Tech Stack

- **Vanilla JS** — вся логика без фреймворков
- **OpenWeatherMap API** — получение погоды по городу
- **LocalStorage** — сохранение имени и города
- **CSS3** — адаптивный дизайн, плавные переходы

## 🎯 Функционал

| Элемент          | Описание                                                                                |
| ---------------- | --------------------------------------------------------------------------------------- |
| **Часы и дата**  | Автообновление каждую секунду                                                           |
| **Приветствие**  | Меняется в зависимости от времени суток (morning/afternoon/evening/night)               |
| **Смена имени**  | Ввод имени сохраняется в LocalStorage                                                   |
| **Погода**       | Поиск по городу, температура, описание, скорость ветра, влажность                       |
| **Слайдер фона** | Стрелки влево/вправо переключают фоновые изображения (20 шт. для каждого времени суток) |
| **Аудиоплеер**   | Плейлист из 6 треков, прогресс-бар, громкость, переключение треков                      |
| **Плейлист**     | Отображение списка треков, подсветка активного                                          |

## 🌐 API

- **OpenWeatherMap** — `api.openweathermap.org`
- **Изображения** — из репозитория `rolling-scopes-school/stage1-tasks`

## 🧠 Что дал проект

- Работа с асинхронными запросами (`fetch`, `async/await`)
- Управление аудиоэлементом (`Audio` API)
- Работа с LocalStorage для сохранения состояния
- Обработка событий (клики, изменение полей ввода, загрузка страницы)
- Модульная структура (импорт/экспорт)
- Динамическая смена стилей и классов
